## Rebuild

```
uv run python -m report.make_figures          # figures/, from the simulator
uv run python -m report.tables                # tables.md, the sweep tables
uv run python -m report.size_study            # size_table.md, the size sweep
uv run python -m report.generate_pdf_report   # the PDF
uv run python -m report.check_pdf             # self-contained, sections, DOI resolution
uv run python -m report.check_numbers         # every quoted number still matches the model
```

or all of it, with the tests, in one command:

```
uv run python -m tools.check_all              # prints "all steps passed"
```

`check_pdf.py` refuses a file that is missing a section marker, carries embedded files or
non-URL actions, has fewer than 25 pages, or contains a DOI that does not resolve through
the handle registry (`--offline` skips the network step). `check_numbers.py` recomputes the
66 numbers the text quotes and refuses a PDF that does not contain them; the builder and the
gate both read `numbers_source.py`, so those numbers cannot drift.

Every figure except the GUI capture is drawn at build time from the simulator. The GUI
capture is a photograph of the running program, not a build product: it is checked in because
a screen capture is not reproducible pixel-for-pixel, and
`uv run python -m report.capture_gui` regenerates it on a virtual X display (Xvfb + Tk +
ImageMagick), so a capture never touches a desktop session.

## Tables

- `tables.md`: polydispersity, aggregation, solvent/temperature, refractive index, detector
  angle and PDI noise floor, plus the noisy inversion. Generated by `report.tables`.
- `size_table.md`: the size sweep and the inversion residuals. Generated by
  `report.size_study`.
- `cover.pdf`: the cover page, regenerated from assignment 2's copy by `report.make_cover.py`
  (only the date run in the content stream changes).

Both markdown files are generated, never edited by hand; the PDF tables are built from the
same row functions, so the markdown and the PDF cannot disagree.
