# report/

Figures and, later, the PDF report for assignment 2.

## Figures

| file | what it shows | how it is made |
| --- | --- | --- |
| `figures/instrument.png` | the Bragg-Brentano chain the simulator models | `instrument_diagram()` in `make_figures.py` |
| `figures/phase_panel.png` | one simulated pattern for each of the nine phases, 20-90 deg | `phase_panel()` |
| `figures/scherrer.png` | silicon 111 at 5, 20 and 200 nm crystallite size | `scherrer_demo()` |
| `figures/doublet.png` | silicon 422 with and without K-alpha2 | `doublet_demo()` |

Nothing in `figures/` is drawn by hand. Regenerate them all with:

```
uv run python -m report.make_figures
```

The module is run with `-m` so the package `xrdsim` is importable from the assignment
root; a plain `python report/make_figures.py` puts `report/` on `sys.path` instead and
fails to import.

## The PDF

`Assignment_2_XRD_Diffractometer_Report.pdf` is a draft: the graded questions are not in
it because the assignment brief has not been received. It carries the instrument, the
model, the phase table, the four figures and the verification summary.

```
uv run python -m report.generate_pdf_report
uv run python -m report.check_pdf
```

`check_pdf.py` is the gate: it fails if the document is missing a section marker, carries
embedded files, or is shorter than three pages. `check_numbers.py` recomputes the numbers the
text quotes (silicon positions, intensity ratios, the Scherrer range) and refuses a PDF that
does not contain them. The PDF builder and the gate both read `numbers_source.py`, so the
text cannot drift from the model.

## Tables

`tables.md` holds the reflection table of every phase (hkl, d, 2theta, multiplicity,
relative intensity), generated by:

```
uv run python -m report.tables
```

It is generated, never hand-edited, so a number quoted in the report can be traced to the
model that produced it.
