# State of assignment 2, 2026-10-22 15:00

## What exists

A complete, tested simulator for a Bragg-Brentano powder diffractometer, in
`assignments/02-xrd-diffractometer/`. Nine phases, a command line interface, a figure
generator, a generated reflection table, a draft PDF and three gates.

| area | artifact | state |
| --- | --- | --- |
| physics | `xrdsim/` (12 modules) | Bragg positions, structure factors, multiplicities, LP, Debye-Waller, Cu K-alpha doublet, Caglioti profile, Scherrer and Williamson-Hall, Poisson counts, dead time, specimen displacement |
| data | `data/SOURCES.md`, `data/scattering_factors.json` | every constant sourced, graded and dated; the factor table regenerates from Waasmaier-Kirfel |
| tests | `tests/` (111 tests) | unit, analytic and end-to-end; each phase is checked against its published strongest line and against the peaks its own scan produces |

| documents | `TASK.md`, `VERIFICATION.md`, `docs/` | spec with the brief slots empty, verification record, model description, brief intake checklist, three research notes |

## What is verified

`uv run python -m tools.check_all` runs tests, figures, tables, PDF and both gates; all six
pass. A fresh clone rebuilds every artifact byte-identically (`VERIFICATION.md` section 2.2).

## What is blocked

The assignment brief. `TASK.md` carries `AWAITING BRIEF` in every place that depends on it:
the graded questions and weights, the named samples, the submission rules, and the two
sections of the report those decide.

## Next actions when the brief arrives

`docs/brief_intake.md` is the checklist, in order. The short version: quote the brief
verbatim into `TASK.md`, map each graded clause to an artifact, add any named sample with
`python -m tools.phase_from_cif` (which refuses a phase that misses its published line),
then write one report section per clause and close out with `tools.check_all`.

## Known limits

- The Cu K-alpha wavelengths are provisional; no primary table could be read from this host.
- Caglioti U, V, W and the uniform B = 0.5 A^2 per site are stated defaults, not fitted values.
- No simulated pattern has been compared with a measured scan.
- Absolute intensities are not modelled, by design.
