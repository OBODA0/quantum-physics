# report/

Everything the assignment is submitted from, plus the working files behind it.

| file | status |
| --- | --- |
| `Assignment_1_PL_Spectroscopy_Simulation_Report.pdf` | **current** — the submission: design, the three dye spectra, the excitation sweep, the multi-dye comparison, verified references, and a fourteen-file code appendix. Rebuild it after any text change. |
| `report_figures/*.png` | current — generated by `generate_assignment_figures.py`; these are the "screenshots" the announcement asks for |
| `numbers.md` | current — generated by `generate_numbers.py`; every number the report quotes comes from here, so the text cannot drift from the code |
| `references/AUDIT.md`, `references/claims.json` | the audit of the earlier draft, with a status note at the top: its findings were applied in the rewrite, so read it as the evidence behind the current reference list |
| `settings.py` | the optical conditions shared by the figures and the numbers (concentration, path length, stray level, detection range) |
| `generate_assignment_figures.py` | draws the instrument diagram and all three questions' figures |
| `generate_numbers.py` | writes `numbers.md` |
| `generate_pdf_report.py` | builds the submission PDF; reads the figures and the appendix sources from the repository and fails loudly if any is missing |

Rebuild everything from a clean checkout:

```
uv sync
uv run python report/generate_assignment_figures.py
uv run python report/generate_numbers.py
uv run python report/generate_pdf_report.py
```

Before uploading, run the gate on the built file:

```
uv run python report/check_pdf.py
```

It resolves every DOI printed in the PDF, counts the appendix files and the embedded
figures, and checks the metadata. Then upload the PDF alone - no separate figures, no
repository link.
